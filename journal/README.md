# DETOUR Journal

구현 과정에서의 고민, 선택, 실패, 배운 점을 날짜와 함께 보존합니다.

## 기록 원칙

- 고민을 말하거나 작업을 끝내면 Codex가 날짜·시간을 포함한 기록으로 정리합니다.
- 기술적인 결정뿐 아니라 “왜 이 기능을 먼저 만들었는가”도 기록합니다.
- 원본 기록은 지우지 않고 주간 회고에서 요약만 추가합니다.

## 기록 명령

- “오늘은 끝나자”라고 하면 오늘의 공부·구현·고민 기록을 정리하고 다음 작업을 남깁니다.
- “기록 확인해보자”라고 하면 지금까지의 일지를 날짜순으로 요약합니다.
- “일주일이 끝났어”라고 하면 해당 주의 공부와 구현 완료 여부를 점검하고 주간 회고를 작성합니다.
- 정해진 시간에 보내는 자동 알림은 사용하지 않습니다.

```md
## 막힌 점과 해결 과정

## 다음 작업

## 기록 시각
```
