# DETOUR Journal

구현 과정에서의 고민, 선택, 실패, 배운 점을 날짜와 함께 보존합니다.

## 기록 원칙

- 고민을 말하거나 작업을 끝내면 Codex가 날짜·시간을 포함한 기록으로 정리합니다.
- 기술적인 결정뿐 아니라 “왜 이 기능을 먼저 만들었는가”도 기록합니다.
- 원본 기록은 지우지 않고 주간 회고에서 요약만 추가합니다.

## 일일 기록 템플릿

```md
# YYYY-MM-DD — Day N

## 구현한 것

## 막힌 점과 해결 과정

## 다음 작업

## 기록 시각
```
