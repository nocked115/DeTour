## 공부한 것

- HTML은 `main` 안에 소개 영역(`section.hero`), 기능 설명(`section.features`), 입력·결과 체험 영역(`section.demo`)을 순서대로 배치해 화면의 뼈대를 만든다.
- CSS는 `:root`의 색상 변수, Grid 레이아웃, 그리고 `@media (max-width: 760px)` 규칙으로 디자인과 모바일 화면을 담당한다.
- JavaScript는 입력 요소를 `getElementById()`로 가져오고, 버튼의 `click` Event에서 선택값을 읽어 추천 카드 3개를 만들어 화면에 넣는다.
- 현재 위치·날씨·추천 결과는 이미 화면에 있지만, 장소·이동 시간·날씨는 아직 실제 API가 아닌 예시 데이터다.
- 실행 확인: 서울숲역 → 성수역, 60분, 비, 카페 선택 시 실내 카페 TOP 3가 표시됐다.

## 구현한 것

- `detour-landing.html`의 단일 추천 문장을 TOP 3 추천 카드로 확장했다.
- 사용자가 남은 시간과 활동을 선택하고 버튼을 누르면, 선택 조합에 맞는 카드 3개가 표시된다.
- 각 카드는 순위, Match 점수, 예상 시간·비용, 추천 이유를 보여준다.
- JavaScript 문법과 변경 사항을 검사했다.
- 강사 피드백 안내 영역을 삭제하고, 현재 위치·도착 위치·날씨 입력을 추가했다.
- 비가 오는 날에는 실내 장소를 우선으로 보여주는 임시 추천 데이터를 추가했다.
- 실제 위치 기반 이동 시간은 지도 API를 연결하는 다음 단계에서 계산하기로 했다.
